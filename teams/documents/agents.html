How MindSuite reads your documents

Specifications, handbooks and diagrams say what the system was meant to do. A team of 12 agents reads them and finds what the Documents & diagrams card promises: business rules, processes, glossary and intended architecture, each with the exact line it comes from. It also says how current each document is, and where documents contradict each other.

Four rules the whole system follows

Documents onlyThe files you give, read in memory on the backend. Nothing is fetched from SharePoint or Confluence.
Secrets never shownA password written in a document is reported as file and line only, and that line is never sent to Claude.
Every claim is citedEach rule, term, step and link points to the document line or diagram shape it comes from.
People decideDocuments can be out of date. Your analysts confirm, correct or reject each result.

What the agents need from your analysts and architects

GiveHow
Specifications and manualsWord (.docx), PowerPoint (.pptx), PDF with a text layer, Markdown or text. Up to 20 MB per file.
Wiki pagesConfluence or SharePoint pages exported as HTML (Export → HTML, or Save page as)
Diagramsdraw.io / diagrams.net files (.drawio, also compressed) and Visio (.vsdx)
Cannot be readOld .doc, .vsd and .ppt files and scanned PDFs: save them as .docx, .vsdx or a PDF with text. The agents list them and ask.

Every agent

What is running today

All 12 agents run in the same MindSuite agent backend as the other teams. In MindSuite, open Record evidence → Documents & diagrams → Run the documents & diagrams agent team.

Ten rule-based agents always run and nothing leaves the backend machine. The business-rules and business-story agents run only with a Claude API key on the backend and your consent for that run.
